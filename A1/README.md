# A.1 - Replacement Source Photographs

Nine user-supplied HEIC photographs are used in this order: IMG_8443, IMG_8444, IMG_8445, IMG_8446, IMG_8447, IMG_8448, IMG_8450, IMG_8451, IMG_8452.

HEIC originals are preserved in originals/ with verified SHA256 copies. Full-resolution sRGB JPGs are in images/. Previews use 1008 x 1344 pixels for annotation; point coordinates are converted back to each original resolution using pixel-center scaling. Images are not cropped or geometrically corrected.

The set follows the same building from its reflective front facade to the glazed/right-hand side. Reflections, vegetation, possible camera movement, and differing framing can affect a single homography. A fixed center of projection is not established.

This is one continuous set. The full A.1 assignment still requires a second set. Earlier A1/A2 work is retained in ../archive/2026-10-30-before-photo-replacement/.

IMG_8448 was added between IMG_8447 and IMG_8450 to bridge the original overlap gap. The pre-bridge A1/A2 and site are preserved in ../archive/2026-10-30-before-8448-bridge/.
